# Hub 48 infographic vua và anh hùng Việt Nam

Website tĩnh: 1 trang hub (`index.html`) + 48 trang nhân vật trong `pages/`.

- `index.html` — timeline 8 triều đại, 48 cards có thumbnail chân dung, ô tìm kiếm, responsive mobile.
- `pages/` — 48 file `.html` standalone (mỗi trang: chân dung, 4 mốc đời, 4 thẻ thành tựu, giai thoại, 3 câu hỏi trắc nghiệm có chấm điểm).
- `thumbs/` — 48 thumbnails chân dung (`.webp`).

Mở `index.html` trên trình duyệt là chạy, không cần build hay server.

Học liệu của NAADLD@2026.
